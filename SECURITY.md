# Security policy

Please do not report credentials, private keys, public server addresses, or
other sensitive data in a public issue. Use the repository's private security
reporting mechanism when available; otherwise contact the maintainer privately.

Before opening an issue, remove personal paths, hostnames, tokens, and generated
SDK/toolchain artifacts from logs. The project deliberately requires explicit
`ISB_REMOTE_HOST` and `ISB_REMOTE_USER` values and never ships remote defaults.
