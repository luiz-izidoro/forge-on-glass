# Code of conduct

## Commitment

We want participation in this project to be safe and productive for everyone, regardless of
experience, identity or background.

## Expected behavior

- Be direct, specific and respectful when discussing code and design.
- Assume good faith and focus on the problem, not the person.
- Give and accept technical feedback gracefully.
- Respect privacy: never post real device identifiers, credentials or personal data.
- Credit others' work and respect the licenses of third-party material.

## Unacceptable behavior

- Harassment, discrimination, threats or personal attacks.
- Publishing private information without explicit consent.
- Deliberate disruption, spam or bad-faith security testing.
- Repeatedly ignoring project norms after clear feedback.

## Enforcement

Maintainers may edit or remove contributions and may restrict participation when this policy is
violated. Reports are handled confidentially. Use GitHub Security Advisories for sensitive
security reports, or contact a maintainer directly for conduct concerns.

## Scope

This policy applies in project spaces and in interactions that represent the project.
