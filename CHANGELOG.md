## 0.2.0 — 2026-09-02

- arm64e.v1/PAC is the only operational and release profile.
- Added the arm64e acceptance matrix for UI, Foundation/Dispatch, TortureTest,
  debug, hybrid, CoreML/Vision/Accelerate, FoundationModels, NaturalLanguage
  and embeddings.
- Fixed UIKitCore generic Swift linking with `-client_name UIKit`.
- Added the NLEmbedding bridge and phased runtime diagnostic.
- Added weak-link validation and a negative strong-link FoundationModels fixture.
- Added newcomer onboarding, documentation, privacy and release gates.
- The current arm64e cache is generated by the canonical Linux/VM workflow and
  validated before transfer.
- User-confirmed S3/S4 evidence applies to iPhone17,1 / iOS 26.6 / LiveContainer;
  other devices, iOS versions and LiveContainer versions remain untested.

## Unreleased

- Consolidated the repository to the arm64e.v1/PAC profile.
- Removed obsolete compatibility builders, remote-link helpers, fat-slice
  tools, superseded probes and archival handoff/report files from the checkout.
- Repaired configurable sysroot/toolchain paths, transient scan retries,
  hybrid linking and pure-UI argument initialization.
